# AlgoRover Research setup

Call `search_strategies` with `{}` to open the inline strategy catalog before replying. Point to the card's search and strategy controls. Mention that browsing is public and starting a personal backtest requires OAuth.

If the remote service cannot be reached, report that connection failure. Do not install or start a local Runtime as a substitute.
